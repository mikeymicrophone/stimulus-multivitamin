Creamery vat card

Morning make at the Tillamook creamery. Three cards for the same Jersey vat: one with defaults written out, one with bare types, and one that names the defaults directly. None of them has been filled in.

Morning vat

Defaults live in the controller: Jersey, 86 degrees, a mesophilic culture, and an unflagged card. Spare degrees name a type and no default.

No mismatched card filed.

Plain vat

The same blanks, declared as String, Number, Array, and Boolean with no defaults.

Shorthand vat

The defaults are the values themselves, including a flag left false.
